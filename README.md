# 🪟 Saikat Barai - Windows XP Retro Portfolio

An authentic **Windows XP (Luna Blue)** styled interactive portfolio website crafted for **Saikat Barai**. It features old-school animations, sound synthesizer effects, interactive Explorer file navigation for engineering projects, and **Rover**, an intelligent retro AI Search Companion assistant that responds to any questions about Saikat with deep, detailed answers!

---

## 🌟 Highlights & Features

### 1. 📁 "My Projects" Explorer Folder
* Authentic Windows XP Explorer interface with sidebar tasks, details view, and file view switcher (Large Icons vs. Detailed Table).
* **Included Projects**:
  * **Own Vector Database (C++)**: Built from scratch in modern C++ with Euclidean, Manhattan, and Cosine similarity metrics, HNSW graph indexing, KNN retrieval, and Ollama embedding integration.
  * **AI Resume Screening System (Python/Groq)**: PDF resume parser using Pydantic, automated candidate matching & ranking with Groq's Llama 3.3 70B Versatile.
  * **LeetCode-Style Coding Platform**: Full-stack platform using Node.js, Express, PostgreSQL, and Prisma with automated code testing.
  * **Smart India Hackathon (SIH)**: Team Leader of *Bottleneck*.
* Double-clicking any project launches an interactive Windows XP **Project Inspector** dialog with full architectural highlights and direct GitHub links.

### 2. 🐕 Rover - The Windows XP AI Search Companion
* Classic animated search dog companion sitting on the desktop with nostalgic speech bubbles.
* Dual modes: Floating desktop puppy or full-featured Search Companion chat window.
* **Intelligent Knowledge Engine**:
  * Accurately answers questions regarding Saikat's education (Jalpaiguri Government Engineering College, CGPA 8.11), summer research internship at NIT Jamshedpur (ADHD detection feature selection), technical stack, vector search, Groq LLM pipelines, and contact details.
  * Instant action triggers: e.g., asking *"Show me his projects"* automatically opens the Projects window; asking *"How can I contact him?"* opens the contact window.
  * Typewriter text streaming effect with nostalgic sound feedback.

### 3. 📄 WordPad Resume Viewer
* Authentic Windows XP WordPad application showing Saikat's complete formatted resume.
* Includes one-click **Print / Save as PDF** support.

### 4. 🖥️ My Computer & System Properties
* Multi-tabbed classic dialog (General, Skills & Hardware, Experience, Education).
* Shows system specifications, programming languages, databases, developer tools, and coursework.

### 5. 📟 Command Prompt (`cmd.exe`)
* Interactive vintage DOS/Windows command line.
* Commands: `help`, `about`, `projects`, `skills`, `contact`, `rover <query>`, `matrix`, `cls`, `crash` (BSOD Easter Egg!).

### 6. 💣 Minesweeper Game
* Fully playable 9x9 retro Windows XP Minesweeper game with digital LED counters and animated smiley button.

### 7. 🔊 Web Audio Retro Sound Synthesizer
* 100% self-contained synthesized retro sounds:
  * Windows XP Startup chord progression
  * Folder navigation clicks
  * Balloon notification pops
  * Error chords & shutdown tunes
* Volume toggle and CRT scanline overlay switch right in the taskbar tray.

## 🚀 How to Run

Because this project is built with zero external runtime dependencies, you can open it immediately:

### Option 1: Direct File Launch
Simply double click `index.html` to open it in any modern web browser (Edge, Chrome, Firefox, Brave, Safari).

### Option 2: Local HTTP Server (Python)
```bash
cd "C:\Users\saika\.gemini\antigravity\scratch\saikat-xp-portfolio"
python -m http.server 8000
```
Then visit: `http://localhost:8000`

### Option 3: Deploy to GitHub Pages / Vercel / Netlify
Push this directory to a GitHub repository and turn on **GitHub Pages** under repository settings (Deploy from Branch -> `main` / `root`). It works instantly with zero build steps!
